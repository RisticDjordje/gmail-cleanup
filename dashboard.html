One-time setup

The extension talks to Gmail directly from your browser using your own Google OAuth client, so your mail never passes through anyone else's server. It takes about 5 minutes. The README has more detail on each step.

  1. Open the Google Cloud Console and create a project.
  2. Enable the Gmail API for it.
  3. Configure the OAuth consent screen: choose External, and add your Gmail address as a test user.
